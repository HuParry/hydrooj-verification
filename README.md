# hydrooj-verification

Hydro OJ 邮箱验证码插件。将注册、找回密码或用户名、更换邮箱时的邮件链接验证改为 6 位数字验证码，用户无需离开当前页面打开验证链接。

适用于 Hydro 5.1.0 及以上，使用 Hydro 默认界面和 SMTP 发信服务的站点。

## 使用场景

1. 注册时直接输入邮件中的验证码，再设置用户名和密码。
2. 忘记密码或用户名时，通过验证码进入 Hydro 原生找回页面。
3. 更换邮箱时，向新邮箱发送验证码，确认归属后完成更换。

## 作为 Hydro 插件安装

以下命令均使用运行 Hydro 的用户执行，需要已安装 Hydro 和 Yarn 1。

```sh
yarn global add hydrooj-verification
hydrooj addon add hydrooj-verification
pm2 restart hydrooj
```

插件的模板和脚本由 Hydro 启动时自动加载，无需单独构建或修改 Hydro 源码。实际 PM2 进程名不同时，请替换 `hydrooj`。

如果此前通过本地源码目录安装，先使用 `hydrooj addon remove <原插件目录>` 移除旧登记，再登记 npm 安装的插件，避免同时加载两份。

## 更新插件

重新执行安装命令即可更新：

```sh
yarn global add hydrooj-verification
hydrooj addon add hydrooj-verification
pm2 restart hydrooj
```

## 在 Hydro 中使用

安装前请在 Hydro 系统设置中配置好原有 SMTP 发信参数。插件直接复用这些设置，无需配置另一套邮件服务。

### 注册

打开注册页面 `/register`，填写邮箱并点击“获取验证码”。收到邮件后输入 6 位验证码，点击“继续”，即可在 Hydro 原生页面设置用户名和密码。

是否启用注册邮箱验证仍由 Hydro 的 `smtp.verify` 设置控制；关闭后保留原生免邮箱验证注册流程。

### 找回密码或用户名

打开 `/lostpass`，填写账号绑定的邮箱并获取验证码。验证通过后，进入 Hydro 原生页面查看用户名、设置新密码。

### 更换邮箱

在安全设置页面点击邮箱旁的“修改”，按原生要求完成身份确认，再填写当前密码和新邮箱，向新邮箱获取验证码。验证通过后，由 Hydro 原生逻辑完成邮箱更换。

如果更换目标邮箱，需要重新获取验证码并复核密码；验证码通过前，原邮箱不会改变。

### 输入验证码

验证码输入框旁提供获取和重新发送按钮。发信期间显示“发送中…”，发送成功后从完整的 30 秒开始倒计时；等待期间按钮不可点击，验证码输入框始终可以输入。

页面会提示检查收件箱和垃圾邮件箱。倒计时结束后可以重新发送；刷新页面不会重复发信，也不会重新开始计时。输入框支持手机数字键盘和浏览器一次性验证码自动填充，保留验证码开头的 `0`。

## 验证码规则

| 项目 | 规则 |
|------|------|
| 验证码长度 | 6 位数字 |
| 有效期 | 10 分钟 |
| 重新发送 | 邮件发送成功后冷却 30 秒 |
| 尝试次数 | 每个验证码最多 3 次，耗尽后需重新获取 |
| 使用次数 | 验证通过后只能使用一次 |
| 邮件发送限制 | 复用 Hydro 原生限制，每邮箱窗口调整为 30 秒；默认每 IP 每小时 30 封，可受原生设置覆盖 |

请在申请验证码的同一浏览器会话中完成验证。重新发送后，同一用途的旧验证码失效；注册、找回和更换邮箱的验证码不能互用。

## 邮件与语言

邮件沿用 Hydro 原生 SMTP 配置、邮件布局、站点样式和页脚，仅将验证链接替换为验证码。找回密码邮件仍包含用户名，纯文本邮件也提供验证码。

支持简体中文、繁体中文、英语和韩语，页面和提示随 Hydro 界面语言显示。邮件语种继续遵循 Hydro 原生规则，邮件主题保持原生的 `Sign Up`、`Lost Password` 和 `Change Email`。

## 处理限制

插件保留原生权限、邮箱格式检查、账号归属检查、黑名单及更换邮箱的密码和身份复核。验证通过后继续使用 Hydro 原生注册、找回和邮箱更换逻辑。

地址栏在后续原生页面中仍可能出现长随机令牌，邮件正文使用验证码。插件不处理第三方登录、双因素认证或自定义插件新增的验证邮件；替换过相关页面或处理逻辑的站点需要单独适配。

卸载插件后，三个流程恢复 Hydro 原生行为。插件不会批量撤销此前已经发送的邮件或签发的令牌。
